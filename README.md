
# Documentación System *matricula Frontend*
![Logo](https://portfolio-b1bb8.web.app/assets/images/projects/system-tuition.svg)

This application is a CRUD (Create, Read, Update, Delete), save files and send email. Developed using Angular, Angular Material.


## Run Locally

1. **Clone repository:**
   First, clone the repository to your local machine. Open a terminal and run the following command, replacing the URL with that of the GitHub repository:
```bash
   git clone https://github.com/davidillanis/matricula-frontend.git
```
2. **Navigate to the project directory:**
   Change directory to move to the project you cloned:
```bash
   cd matricula-frontend
```
3. **Install dependencies:**
   Make sure you have Node.js and npm installed. Then, install the project dependencies by running:
```bash
   npm install
```
4. **Inicia el servidor de desarrollo:**
   Once the dependencies are installed, you can start the Angular development server with the following command:
```bash
   ng serve --open
```
